# THE WORLD IN ONE DAY — Wednesday 25 November 2026

A one-page broadsheet front page summing up Wednesday 25 November 2026 in 48 dated, sourced stories across 7 regions, with three illustrated leads, a world map, a five-frame timeline, and a date-check box that keeps earlier days' news out.

The page was drawn as plain HTML with inline SVG and screenshotted once; this program only verifies and copies the finished image.
